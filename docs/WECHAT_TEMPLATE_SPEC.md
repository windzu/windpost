# WindPost 公众号模板

WindPost 的自定义公众号模板由 Agent 创建，插件只负责发现、校验、预览和使用。

模板协议的唯一事实来源：

- [`skills/create-windpost-wechat-template/references/template-spec.md`](../skills/create-windpost-wechat-template/references/template-spec.md)

模板创建 Skill：

- [`skills/create-windpost-wechat-template/SKILL.md`](../skills/create-windpost-wechat-template/SKILL.md)

用户模板放在 Vault 的：

`WindPost/Templates/WeChat/<template-id>/`

创建完成后，在 WindPost 公众号预览区点击「刷新」并选择模板。
