# 我如何把一篇长文变成小红书

以前我会为每个平台重新写一遍，时间花了不少，内容却越来越散。

现在我的做法很简单：

1. 先在 Obsidian 完成长内容；
2. 只提取一个最值得单独传播的判断；
3. 用第一人称重写标题和开头；
4. 保留三到五个要点，删掉不影响结论的背景；
5. 在 WindPost 里检查卡片分页，再打开小红书填写。

真正节省时间的不是「一键搬运」，而是让每个平台只承担适合它的表达。

这篇示例没有 `cover_text`，WindPost 会直接用标题生成封面。只有当封面需要另一句文案时，才添加这个可选属性。
